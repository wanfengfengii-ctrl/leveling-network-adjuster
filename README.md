# 隧道复测统一平差工作台

纯前端水准网（高程控制网）统一平差工作台：TypeScript + React + Vite 实现，
**不调用任何外部服务**——点表、观测表的校验、加权最小二乘平差、拓扑绘制全部在浏览器本地完成。

适用于隧道复测中“共享观测点必须统一平差、无基准支网不得混入成果”的要求：
只要全网存在输入错误或数值上秩亏（无基准支网），就不出任何旧成果。

## 运行

## 数据规则

**点表**声明完整点集，每行：

| 字段 | 规则 |
| --- | --- |
| 名称 | 非空、全表唯一 |
| 类型 | `基准` 或 `未知` |
| 高程 | 基准点必须填有限数值；未知点**不得**填写 |

**观测表**每行：

| 字段 | 规则 |
| --- | --- |
| 起点 / 终点 | 只能引用点表中已声明的点名称；不能同名（自环非法） |
| 高差 h | 有限数值 |
| 标准差 σ | 有限数值且 **0 < σ ≤ 100** |

错误（重复点、自环、未知引用、空/非有限/越界字段等）按**表（点表优先）、行号、字段固定次序**
稳定汇总；**任一错误存在即清空旧成果**，界面不显示任何平差结果，复制按钮禁用。
错误全部修正后自动恢复计算。

## 平差数学模型

### 1. 观测方程与权

对每条观测（起点 s → 终点 e，高差 h，标准差 σ）：

$$
H_e - H_s = h + v
$$

残差 **v = 平差高差 − 观测高差 = (Ĥ_e − Ĥ_s) − h**。

按**点表顺序**为所有未知点建立未知数列，基准点高程作为已知常数移入右端项。
第 i 条观测的系数行：

- 终点 e 为未知点：`A[i, col(e)] = +1`；为基准点：右端项减去 H_e
- 起点 s 为未知点：`A[i, col(s)] = −1`；为基准点：右端项加上 H_s

权取 **w = 1/σ²**。为避免 σ 为合法极小正数（如 1e-200）时 1/σ 溢出，
求解时行权取相对尺度 **c = σmin/σ ∈ (0,1]**（σmin 为全网最小标准差）：
加权目标整体乘公共常数 σmin² 不改变极小化解。平差高程与残差不受影响；
报告的加权残差平方和仍为规范定义的 **Σ(v/σ)²**，在 DD 下**先除后平方**
（v=σ=1e-200 时精确得 1，不会下溢为 0 或上溢）：

$$
\min_{x}\; \sum_i \frac{v_i^2}{\sigma_i^2}
\;\Longleftrightarrow\;
\min_{x}\; \sum_i \Bigl(\tfrac{\sigma_{\min}}{\sigma_i}\Bigr)^2 v_i^2
$$

### 2. 带列主元 QR（自行实现）

对加权后的设计矩阵 A（m×n）做 Householder QR，**每一步在剩余列中选欧氏范数最大的列**；
范数相同时选取原列序号最靠前者。R 的列不做物理交换，主元选取次序记录于置换 `perm`，
解出后按 `x[perm[k]] = z[k]` 还原；回代后再做两步迭代改进
（δ 由同一组 R̃、Q 解 R̃δ=Qᵀ(b−Ax)，x←x+δ），使解的前向误差与观测数无关。
代码见 `src/lib/matrix-dd.ts`，未调用任何现成求解器或线性代数库。

**内部全程使用自行实现的 double-double 高精度算术**（`src/lib/dd.ts`，
用两个 double 表示约 106 位有效数字，two-sum/Veltkamp 拆分/Newton 除法与开方）。
原因：高差接近 1e9 时 double 的 ULP≈1.19e-7，普通 double QR 解的不同减法路径
会产生 ~2.4e-7 的舍入噪声，使数学上相等的并列残差出现假差异（毫米级残差被
机器精度淹没）。DD 将该噪声压到 1e-23 以下；输入十进制字符串按精确值读入
（`parseDecimal`），高程、残差、平方和都由同一批未舍入 DD 结果计算，
仅在最终展示时转回 double。这也保证 σ=v=1e-200 时 (v/σ)² 精确为 1。

### 3. 秩亏判据（无基准支网的唯一判定方式）

未知量非空时，逐主元检查：

$$
|R_{kk}| \le 10^{-10}\,|R_{11}|
$$

一旦成立即判定**整网秩亏**（观测数不足、存在未联测到基准的无基准支网、
孤立未知点等情形都会由该数值判据自然检出）。此时只显示原因、不显示成果、禁用复制；
**不做任何额外的连通性搜索**。未知量个数为 0（全网皆基准点）时不建方程，直接复算残差。

### 4. 成果与展示

合法时，所有展示（点高程、平差高差、残差、加权残差平方和 Σw·v²，w=(σmin/σ)²）
均来自**同一批未舍入**的解算结果：

- 数值显示为三位小数，采用**恰半远离零**（half away from zero）规则，
  例如 1.2345 → 1.235、−1.2345 → −1.235（`src/lib/format.ts`）；
- **并列最大未舍入 |v|** 全部以红色标出（先在未舍入 DD 残差上求最大值，
  再按未舍入值比较并列，而非比较显示文本）。最小二乘解在 QR 回代后做
  **两步迭代改进**（同一组 QR，反复以 R̃δ=Qᵀ(b−Ax) 修正），把随观测数 m
  累积的求解误差从 O(m·εdd) 压回 O(εdd²)（实测 m=73、高差 1e9 时残差噪声
  仅约 2.5e-54）。每行残差只含一次 DD 减法，其不可分辨误差界取
  **4·εdd·max(|平差高差|, |观测高差|)**——按**本行操作数**而非全网最大尺度
  （否则基准间的长直达观测会吞掉不相干短观测的微小真实差）；两行并列要求
  |v| 之差不超过两行误差界之和（十亿高差下单行约 8e-23，可分辨 1e-21 级闭合差）：
  - 全部残差为 0（完全相容的水准网，含**只有一条零残差观测**的情形）时，
    零残差就是最大值且彼此并列，这些行**照常标红**；
  - 残差真实不等（如闭合差 1e-21 产生的 −2e-22 与 −8e-22）时，只标红
    绝对残差最大的行，较小残差与零残差不标红；
  - 操作数为亚正常值（如 5e-324）时误差界下溢为 0，零与非零严格区分；
- 拓扑图为确定性力导向布局（无随机数、无外部图库），
  基准点画方块、未知点画圆点，边箭头表示观测方向，支持按钮与滚轮缩放，
  最大残差边同步标红。

### 5. 复制文本

点击“复制高程与残差”，剪贴板内容先按**点表顺序**输出点高程（2 列），
再按**观测顺序**输出残差（3 列），逗号分隔，均保留三位小数：

```
BM1,100.000
P1,102.371
…
BM1,P1,0.021
…
```

秩亏或存在输入错误时复制按钮禁用；修正后自动恢复。
